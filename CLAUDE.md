# Dimension Dash

2D mobile auto-runner (Unity 6, `6000.6.7f1`). The player runs right automatically; jump and switch
between two dimensions (REALITY / SHADOW) to make platforms and obstacles solid or ghosted.

## Layout

- `Assets/Scripts/` — all game code (flat, no asmdef yet, compiles into `Assembly-CSharp`)
  - `GameManager` — persistent singleton (`DontDestroyOnLoad`): play state, attempts, restart
  - `LevelManager` — per-scene singleton: current `Dimension`, broadcasts switches to every `DimensionSwitcher`
  - `DimensionSwitcher` (abstract) → `ColorSwitch` → `DimensionProperty`: objects reacting to dimension switches
  - `PlayerController` — movement, jump, collisions, input (legacy Input Manager)
  - `StringHelper` — tag/layer name constants; keep in sync with Tags & Layers in ProjectSettings
- `Assets/Scenes/TestScene.unity` — the only scene in the build (contains level 1)
- `Assets/Prefabs/` — Player, Platforms, Obstacles, UI
- `Assets/TextMesh Pro/` — imported TMP essentials; do not edit

## Controls

Keyboard: `D` (hold) = jump, `A` = switch dimension. Touch: right half = jump, left half = switch.

## Working rules

- Only edit `.cs` files directly. Scenes, prefabs, `.asset` and `.meta` files are Unity YAML; change them
  through the Unity Editor (or a Unity MCP tool if one is connected), never by hand, and never delete/rename
  a `.meta` file separately from its asset.
- When creating, moving or renaming a script, the class name must match the file name, and the `.meta`
  must move with it (or let Unity regenerate it — that breaks references in scenes/prefabs).
- The Editor is usually open: after editing scripts, Unity recompiles on focus. Compile errors appear in
  `~/Library/Logs/Unity/Editor.log` (grep for `error CS`).
- Never read or edit `Library/`, `Temp/`, `Logs/`, `obj/`, `UserSettings/` — generated by Unity.
- Prefer Unity 6 APIs: `Rigidbody2D.linearVelocity`, `FindObjectsByType`, `FindFirstObjectByType`.
- Physics-driven objects should be moved in `FixedUpdate` via the Rigidbody, not `transform.Translate`.
